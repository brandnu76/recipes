These WOFF2 files are the latin and latin-ext subsets of fonts used on Carroll Lowcountry Table.

- Cormorant Garamond, SIL Open Font License 1.1, https://fonts.google.com/specimen/Cormorant+Garamond
- Fraunces, SIL Open Font License 1.1, https://fonts.google.com/specimen/Fraunces
- Pinyon Script, SIL Open Font License 1.1, https://fonts.google.com/specimen/Pinyon+Script
- Source Sans 3, SIL Open Font License 1.1, https://fonts.google.com/specimen/Source+Sans+3

Self-hosted so recipe pages can use brand typography offline and so the stylesheet no longer blocks on fonts.googleapis.com.
